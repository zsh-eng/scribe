AI Detection Pipeline Verification

How speeches get from Hansard to Pangram and back: the President's Address pilot, the wider set of prepared speeches, and the portraits shown in the explorer. Each step shows the code that does the work and a command that checks it. Every expected output and every figure on this page came from running that code on .

The pipeline

What each check needs

Results folder
Python 3 and the shared presidents_address, prepared_speeches and photos folders, placed under data/ai_detection/.
Repo checkout
The repository with uv installed, plus the results folder. No database, Pangram key or network.
Repo + database
Also the Second Reading SQLite database, opened read-only. The Drive folder one level above the results holds a copy as parliament.db, ; place it at data/parliament.db.
